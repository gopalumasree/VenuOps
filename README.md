## Start here

1. Open **Download** for the tool you need.
2. Select its named **Public ZIP** under **Assets**. The automatic **Source code** archives contain repository documentation, not the application.
3. Extract the complete ZIP and follow the included guide.

Each tool has its own version history, release notes and issue page. Earlier versions remain available from that tool's **Releases** page. Check the release notes for validation scope and current limitations before use.
